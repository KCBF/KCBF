AI・機械学習、コンピュータグラフィックス、リアルタイム3D、ゲームテクノロジー、開発ツール、アプリケーション基盤を横断するソフトウェア開発。主な使用言語はC++、C#、Python、Rust、TypeScript、JavaScript、Java。Unity、Blender、WebGL、画像生成モデル、コンピュータビジョン、モデル推論、アセットパイプライン、アニメーションシステム、バイナリフォーマット、シリアライゼーション、データ変換、自動化、Webアプリケーションなどを扱う。仕様が公開されていない、または不完全なシステムを対象としたデータ構造・バイナリデータ・ファイルフォーマット・ランタイム挙動の解析、インポート／エクスポートおよび変換パイプラインの実装、AIモデルのアプリケーション統合、推論処理やリソース使用の最適化、コンテンツ制作環境とランタイム・デプロイ環境間の統合などに取り組む。低レイヤーのデータ処理からアプリケーション層までを対象とし、特にシステム間の相互運用性、開発ツール、自動化、技術的制約のある環境での実装を扱う。GitHubには、独自実装、技術検証、ユーティリティ、統合ツール、実験的実装、フォーク、長期的に開発しているプロジェクトなど、複数世代の技術にわたる開発成果を掲載している。
